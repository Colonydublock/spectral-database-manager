Learn how to import mass spectra, IR, Raman, NMR, and UV-Vis files, build a queryable database, match unknown spectra against reference libraries, and export publication-ready reports. Built for chemists, spectroscopists, and lab technicians. **Completely free.** No signup. No paywall. No hidden chapters.
